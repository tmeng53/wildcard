# Coaches

The AI coaches' characters, one folder per coach id as the API names it (`xiaohun` is 毛头, the flat-faced ginger cat in a red coach's jacket; `papa` is 帕帕, a smiling follow-along coach with a blonde high ponytail, a pale blue set and a stopwatch in her hand, whose rig keeps the shared parts she has no art for, `tail`, `whistle` and `cord`, empty so the shared moves still play on her). Each folder has its own `rig.json`, its art in `art/base/<part>.svg` (the same SVG subset and 240×320 canvas as the members' art in `../Placeholder`) an optional `backdrop.json` (`{"version": 1, "backdrop": "track"}`, the colour from `../Placeholder/backdrops.json` its head sits on in its circle, so a light coach never melts into a white page) and its clips in `clips/`: `idle` (loops, with a blink), `cheer` (once) and `crying` (loops, for 解雇: the `cry` part, hidden at rest, shows shut eyes and tears). `moves/` holds the moves every coach shares, each played once: `whistle` (someone checked in), `clap` (a week reached its goal) and `pep-talk` (its 战术板 line); a coach's own `clips/<move>.json` of the same name plays instead. They move parts every coach's rig has, all hidden or still at rest so the coach looks the same standing: `whistle` and its `cord` (split from the torso, drawn where they were), `armLFront` (the left arm in front of the body, swapped in only while the arm is swung clear of the jacket), `toot` and `burst` (sound and cheer lines). So `moves` is never a coach's id. Coaches are drawn flat, with no outlines and one shade per material, so they never wear members' parts. A coach without a folder here has no character in this build, and the app shows a stand-in.
