# Coaches

The AI coaches' characters, one folder per coach id as the API names it (`xiaohun` is 毛头, the flat-faced ginger cat in a red coach's jacket; `papa` is 帕帕, retired from hiring on 2026-11-13 but kept here so squads that hired her and their earlier cards still draw her: a smiling follow-along coach with a blonde high ponytail, a pale blue set and a stopwatch in her hand, whose rig keeps the shared parts she has no art for, `tail`, `whistle` and `cord`, empty so the shared moves still play on her). Each folder has its own `rig.json`, its art in `art/base/<part>.svg` (the same SVG subset and 240×320 canvas as the members' art in `../Placeholder`) an optional `backdrop.json` (`{"version": 1, "backdrop": "track"}`, the colour from `../Placeholder/backdrops.json` its head sits on in its circle, so a light coach never melts into a white page; put it, and `backdrops.json`, at rig version 4 or newer, since older builds refuse the file and would drop the whole coach) and its clips in `clips/`: `idle` (loops, with a blink), `cheer` (once) and `crying` (loops, for 解雇: the `cry` part, hidden at rest, shows shut eyes and tears). `moves/` holds the moves every coach shares, each played once: `whistle` (someone checked in), `clap` (a week reached its goal) and `pep-talk` (its 战术板 line); a coach's own `clips/<move>.json` of the same name plays instead. On the home a coach also plays, when it has them, its own `clips/home.json` (its signature move, looping, in place of `idle`), `clips/doze.json` (looping at night with the lights off) and any `clips/habit-*.json` (one now and then while nothing happens), and a clip for each moment `CoachCharacter.Moment` names (`cheer-mine`, `thumbs-up`, `facepalm`, `wave-off`, `clap-along`, `fist-pump`, `stretch`, `jolt`), else the shared one in `moves/` of that name, else a move it already plays; so a coach's signature moves are art put with `put_art`, never a build. They move parts every coach's rig has, all hidden or still at rest so the coach looks the same standing: `whistle` and its `cord` (split from the torso, drawn where they were), `armLFront` (the left arm in front of the body, swapped in only while the arm is swung clear of the jacket), `toot` and `burst` (sound and cheer lines). So `moves` is never a coach's id. Coaches are drawn flat, with no outlines and one shade per material, so they never wear members' parts. A coach without a folder here has no character in this build, and the app shows a stand-in.
