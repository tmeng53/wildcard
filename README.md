# Wildcard (working name)

An iOS app where friend squads check in every day (练了 / 健康餐 / 坦白放纵餐 / 今日请假条), see each other on a shared track, get a Sunday recap, and share a weekly 3:4 schedule poster.

- `ios/` — the SwiftUI app and its local Swift packages
- `web/` — the invite landing page
- `supabase/` — database migrations, policies and edge functions

Agents and humans: start with [`AGENTS.md`](AGENTS.md).
